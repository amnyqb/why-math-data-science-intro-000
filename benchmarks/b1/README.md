# B1: the beer game on M5

Status: pilot and M5 runs done on the rebuilt (board-game-order) model, forecasts scored; **R1 cost passes** (benchmark 204 exactly, teams 1789 against 2028); **R2 agrees in sign, not in size** (shortened DQN training); **R3 passed only in a narrower form**. Start with [RESULTS.md](RESULTS.md).

| File | What it is |
|---|---|
| [CRITERIA.md](CRITERIA.md) | Success criteria, frozen before any result; every deviation is logged in section 9 |
| `build_model.py` | Generates the four-stage model (and its manifest) as one batch of operations and applies it with `dyn ops` |
| `beer_game_m5.sdm` | The generated model, with its tests and manifest |
| `run_pilot.py` | The harness: in-file tests, T4, the classic step, tuning of P1 and P2 at the same effort, 100 test seeds, paired statistics, robustness, the manifest scenarios |
| `prepare_m5.py`, `run_m5.py` | M5 weekly aggregates (not committed) and the 70-series experiment |
| `forecast/`, `run_forecasts.py` | F2 (AutoETS from `augurs`, a separate Rust crate) and the F1/F2 scoring |
| `make_charts.py`, `to_spreadsheet.py` | the charts, and the model in spreadsheet form for the app |
| `results/*.csv` | Every number in the report, per seed |
| [B1_pilot_report.md](B1_pilot_report.md) | The report, generated by the harness |

Reproduce (about 15 seconds):

```
cargo build -p dynamist-cli
python3 build_model.py && python3 run_pilot.py     # synthetic pilot
python3 prepare_m5.py && python3 run_m5.py         # needs data/raw/ from the M5 Drive package
cd forecast && cargo build --release && cd .. && python3 run_forecasts.py
uv run --with matplotlib python3 make_charts.py
```

The harness uses only the Python standard library. Two runs give byte-identical result files (criterion A3).
