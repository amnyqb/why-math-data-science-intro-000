# Keyboard shortcuts

On Windows and Linux, read ⌘ as Ctrl and ⌥ as Alt.

## Everywhere

| Keys | Action |
|---|---|
| ⌘K | Command palette — any command, sheet or variable by name |
| ⌘R | Run and play over time |
| ⌘S / ⇧⌘S | Save / save as |
| ⌘O | Open |
| ⌘Z / ⇧⌘Z (⌘Y) | Undo / redo |
| ⌘J | Show or hide the results panel |
| ⌘B | Show or hide the side panel (details of the selection) |
| F1 | Function reference |
| ? | Shortcut list |
| ⇧⌘C | Copy the whole sheet as a transparent picture |

## Diagram sheets

| Keys | Action |
|---|---|
| V · S · F · A · C · G · K · N | Tools: select, stock, flow, variable, constant, lookup, arrow, note |
| Esc | Back to select; again to clear the selection |
| ⌘C · ⌘X · ⌘V · ⌘D | Copy (items and a picture), cut, paste, duplicate |
| ⌘A | Select everything on the sheet |
| ⌫ | Delete the selection |
| Shift-click | Add to / remove from the selection |
| Drag on empty space | Select with a box |
| Arrow keys (⇧ for bigger steps) | Nudge the selection |
| ⌥⌘ ← → ↑ ↓ | Align left, right, top, bottom |
| ⌘G / ⇧⌘G | Group / ungroup |
| ⇧⌘M | Make a module from the selection |
| 0 | Zoom to fit |
| Space-drag, scroll | Pan |
| Pinch, ⌘-scroll | Zoom |
| Double-click | Edit a variable's equation · open a module |

## Equation editor

| Keys | Action |
|---|---|
| ↑ ↓ | Choose a suggestion |
| Tab or Enter | Insert the suggestion |
| Esc | Close the suggestions |
| F1 | Function reference, inserting into this equation |
