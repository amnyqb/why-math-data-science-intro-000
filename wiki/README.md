# Dynamist wiki

Dynamist is a desktop app for **system dynamics**: draw stock-and-flow diagrams and causal loop diagrams, write equations, simulate, compare scenarios, optimize, and share results as pictures, tables and dashboards.

This wiki is the shared notebook between the people and the assistants working on Dynamist. Anyone can read and edit it. To ask the builder (the assistant that changes the app) for something, write in **[INBOX.md](INBOX.md)**.

## Folders

- `templates/` — the spreadsheet template (`Dynamist-Model-Template.xlsx`) and the same sheets as CSV files. Generated by the app; regenerate with `dynamist --write-docs wiki`.
- `inbox/` — drop workbooks, notes or pictures here for the builder, then mention them in [INBOX.md](INBOX.md).

## Where things live

- The app's source: `app/src/` (Rust, drawn with egui).
- This wiki: `app/wiki/`. In the app: **Help → Documentation (wiki)** opens this folder.
